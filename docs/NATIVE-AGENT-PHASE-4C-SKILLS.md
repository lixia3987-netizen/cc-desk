## 使用入口

在 native 会话的「运行配置」中点击「读取项目 Skills」，勾选需要的条目，再保存配置。读取列表不调用模型，也不自动启用条目；默认选择为空。会话停止后才能修改，保存后的选择在下一回合生效。

支持以下两种项目相对路径：

- `.agents/skills/<名称>/SKILL.md`
- `.claude/skills/<名称>/SKILL.md`

仅枚举当前授权项目/worktree 根下这两个目录的直接子项，不递归寻找其他项目，也不扫描 HOME、全局 CLI 配置或插件目录。同名 Skills 以完整相对路径区分，不因名称相同而覆盖或合并。最多选择 16 项。

发现列表只提供路径等来源信息，不把 frontmatter 解释为模型、工具权限或执行配置。选择保存的是项目相对路径；每个新回合重新读取选定文件。已选择的文件丢失、越界、被链接替换、不是普通 UTF-8 文件或超过限制时，阻止该回合，并让用户修复来源或取消选择；不静默丢弃已选项后继续执行。

## 指令、预算与权限

`CLAUDE.md` 与 `AGENTS.md` 继续按项目根到目标目录逐层加载：深层规则优先，同层冲突以 `AGENTS.md` 为准。所选 Skills 作为任务方法补充，不改变这些作用域和优先级；用户明确指令及宿主权限始终优先。

每个 `SKILL.md` 最多 32 KiB，与适用的 `CLAUDE.md`、`AGENTS.md` 共同占用 128 KiB 总预算。完整加载内容也计入既有模型输入估算和发送前自动压缩判断；压缩后重新读取并检查，不能借摘要操作放宽来源限制或输入预算。

选定来源的路径、内容哈希和组合摘要进入回合配置及审批条件。写入或命令在批准后仍须复核所选 Skills；内容变化、删除或替换为不安全来源使旧审批失效，拒绝执行原批准的操作。单次文件加载期间会复核目录和文件身份；跨审批绑定来源路径与内容哈希，不保证检测内容完全相同的普通文件原子替换。历史记录保留当时使用的内容与来源，新回合读取当前文件，不用新文件内容改写旧记录。

文件内容不会自动执行 hooks、脚本、URL、include 或动态命令；frontmatter 也不授予额外工具权限。Skills 引用的辅助文件仍须通过已有文件工具按权限读取，命令仍须单独审批。项目文件访问策略不是操作系统沙箱，批准的程序仍可能访问用户权限范围内的文件和网络。

## 实现边界

- 项目文件读取复用现有路径、符号链接、目录身份、取消和大小检查；被宿主排除的目录不能成为 Skills 来源。项目根以别名路径提供时，先绑定其真实目录，再读取来源，避免读取后才发现根已指向另一目录。
- 工具结果对已展示且内容未变的指令只返回来源元数据，新增或变更的正文按需补给，避免每次读取重复累积完整 Skills 内容；审批仍绑定全部适用来源的完整摘要。
- 沿用会话运行、恢复、压缩和清理屏障。运行期间不变更所选配置，也不因为读取列表或保存配置启动模型或工具。
- 既有会话缺少 Skills 配置时按空选择处理；Claude 会话及默认引擎不变。写入含 `projectSkills` 的新配置后，旧版严格配置校验会拒绝继续该 native 会话；这不表示数据损坏，应保留原数据并使用支持该字段的版本。
- 本批不提供自动匹配或自动启用、全局来源、Claude 命令目录、技能安装/市场、脚本自动执行，也不接入 MCP 或新增模型协议。
