# 设置分类与作用范围

设置使用两级菜单。一级菜单按用途分组，二级标签定位具体页面，页面内用表单分组管理相关配置。

| 一级菜单 | 二级页面 | 内容 |
| --- | --- | --- |
| 模型与上下文 | 模型连接 / 模型导入 / 上下文预算 / 自动压缩 | 自研 Agent 连接、Claude 配置导入、输入预算、输出预留、压缩策略 |
| 运行与权限 | 运行限制 / 失败恢复 / 权限与审批 | 并发数量、单回合调用与时长限制、有限重试、Claude CLI 权限 |
| 工具与扩展 | MCP 连接 / 会话工具 | 全局连接库、当前 Native 会话的 MCP 与项目 Skills 选择 |
| 终端与CLI | Claude Code / Shell 与终端 | CLI 路径、检测、更新、Shell 路径、终端字号与回滚行数 |
| 工作区与IDE | Worktree / 外部 IDE | 新 Worktree 位置、外部编辑器路径 |
| 外观与字体 | 字体 / 主题 | 聊天与界面字体、字号、字体库、主题 |
| 应用与数据 | 应用行为 / 本机数据 | 通知、托盘与数据目录 |

模型连接页只管理自研 Agent 的连接列表与手动新增、编辑。新增或编辑时进入本页独立编辑视图，列表暂时隐藏，保存和返回操作固定在编辑区底部。普通字段有未保存修改时，先保存连接信息，再设置凭据、读取或切换模型；凭据输入不会覆盖连接草稿。可以先保存服务地址和认证方式，模型留空，设置凭据后读取可用模型，也可手动填写模型 ID。尚未选择模型的连接不能发送消息或执行文本连接测试。

模型导入位于独立页面，可读取 Claude Code 默认配置或选择配置文件，预览后确认创建独立 Native 模型连接。结果明确显示凭据状态与有效期；“编辑此连接”直接定位导入项，缺少凭据时在此补充。“用于新会话”打开预选此连接的自研 Agent 草稿，仍需用户输入任务并发送；连接未就绪时此操作不可用。“前往模型连接”返回列表。离开导入页会放弃未确认的预览，已确认的导入独立保存。Claude Code 的模型配置继续由 CLI 管理。

旧版工作台保存的 Claude 模型与强度覆盖继续保留，可在“终端与CLI → Claude Code”的高级项主动清除默认覆盖，保存后用于新会话。已有会话可在“运行与权限 → 权限与审批 → 当前会话”清除自己的旧覆盖，需先停止会话再保存。此入口只提供回到 CLI 配置来源的操作。

## 默认设置与当前会话

相关页面提供“新会话默认”和“当前会话”作用范围。默认值通过“保存设置”统一保存。当前会话的配置通过页面内“保存配置”独立保存，并应用该会话在各分类中的全部草稿修改。切换分类、二级页面或作用范围会保留模型连接、MCP 连接及当前会话的普通字段草稿，离开连接页会清空尚未提交的密码输入，取消未完成的连接测试或模型列表读取。草稿仅存在本次设置窗口中，不跨重启保存。

底部状态分别汇总全局设置、模型连接、MCP 连接和当前会话尚未保存的修改；连接和导入页没有全局修改时隐藏“保存设置”，这些区域使用自己的保存操作。关闭按钮、×、Esc 和点击弹窗外部使用相同的离开检查：存在未保存修改时，可继续编辑或明确放弃并关闭。模型连接、MCP 连接、已保存的会话配置和字体库的独立保存不会因为关闭设置而撤销。当前会话的已保存配置若在外部发生变化，保留草稿并要求读取新配置，或明确将自己的修改应用到新配置后再保存。

“会话运行策略来源”统一控制输入/输出预算、自动压缩、失败重试和模型/工具调用及运行时长限制，页面会列出这一影响范围。“跟随默认”的会话在下一轮读取已保存的策略，“单独设置”使用自己的策略。模型连接、模型覆盖、MCP 和项目 Skills 保留在会话中，不随运行策略继承。不存在额外的项目默认层；项目 Skills 的选项依赖真实会话的工作目录。

新 Native 会话默认跟随设置。旧会话没有来源标记时保持单独配置，旧输入预算不会自动扩大。切换为单独设置时以当前有效策略初始化，避免恢复过时值。发送及压缩开始时固定策略，正在执行的回合及其历史记录保持原值。

模型窗口是带来源标识的只读能力信息。输入预算可选“跟随模型窗口”或自定义上限，输出上限单独设置。跟随模式使用已知输入限制及窗口扣除输出预留后的较小值；窗口未知时使用有界备用预算，初始为 64,000 tokens。自定义模式进一步受用户输入上限约束。元数据按字段优先读取 provider、catalog，缺失时才使用本地能力表。

## 会话入口

上下文侧栏显示配置和最近回合用量摘要，“会话设置”定位当前会话页面。聊天区保留手动压缩与取消压缩操作。新建会话只显示工作空间、执行引擎、Native 模型选择和任务输入；名称与 Worktree 位于“更多选项”。修改新会话默认设置后，尚未创建的普通草稿同步默认值，Native 已选择的模型连接与模型保持不变。
