# 设置分类与作用范围

设置使用两级菜单。一级菜单按用途分组，二级标签定位具体页面，页面内用表单分组管理相关配置。

| 一级菜单 | 二级页面 | 内容 |
| --- | --- | --- |
| 模型与上下文 | 模型连接 / 上下文预算 / 自动压缩 | 自研 Agent 连接、Claude 配置导入、输入预算、输出预留、压缩策略 |
| 运行与权限 | 运行限制 / 失败恢复 / 权限与审批 | 并发数量、单回合调用与时长限制、有限重试、Claude CLI 权限 |
| 工具与扩展 | MCP 连接 / 会话工具 | 全局连接库、当前 Native 会话的 MCP 与项目 Skills 选择 |
| 终端与CLI | Claude Code / Shell 与终端 | CLI 路径、检测、更新、Shell 路径、终端字号与回滚行数 |
| 工作区与IDE | Worktree / 外部 IDE | 新 Worktree 位置、外部编辑器路径 |
| 外观与字体 | 字体 / 主题 | 聊天与界面字体、字号、字体库、主题 |
| 应用与数据 | 应用行为 / 本机数据 | 通知、托盘与数据目录 |

模型连接页只管理自研 Agent。Claude Code 配置作为导入来源，导入后生成独立 Native 模型连接；Claude Code 的模型配置继续由 CLI 管理。

旧版工作台保存的 Claude 模型与强度覆盖继续保留，可在“终端与CLI → Claude Code”的高级项主动清除默认覆盖，保存后用于新会话。已有会话可在“运行与权限 → 权限与审批 → 当前会话”清除自己的旧覆盖，需先停止会话再保存。此入口只提供回到 CLI 配置来源的操作。

## 默认设置与当前会话

相关页面提供“新会话默认”和“当前会话”作用范围。默认值通过“保存设置”统一保存。当前会话的配置通过页面内“保存配置”独立保存，切换页面或关闭设置会放弃未保存的会话编辑。模型连接、MCP 连接和字体库的独立保存不会因为关闭设置而撤销。

Native 运行策略覆盖输入/输出预算、压缩、重试和模型/工具调用及运行时长限制。“跟随默认”的会话在下一轮读取已保存的策略，“单独设置”使用自己的策略。模型连接、模型覆盖、MCP 和项目 Skills 保留在会话中，不随运行策略继承。不存在额外的项目默认层；项目 Skills 的选项依赖真实会话的工作目录。

新 Native 会话默认跟随设置。旧会话没有来源标记时保持单独配置，旧输入预算不会自动扩大。切换为单独设置时以当前有效策略初始化，避免恢复过时值。发送及压缩开始时固定策略，正在执行的回合及其历史记录保持原值。

模型窗口是带来源标识的只读能力信息。输入预算可选“跟随模型窗口”或自定义上限，输出上限单独设置。跟随模式使用已知输入限制及窗口扣除输出预留后的较小值；窗口未知时使用有界备用预算，初始为 64,000 tokens。自定义模式进一步受用户输入上限约束。元数据按字段优先读取 provider、catalog，缺失时才使用本地能力表。

## 会话入口

上下文侧栏显示配置和最近回合用量摘要，“会话设置”定位当前会话页面。聊天区保留手动压缩与取消压缩操作。新建会话只显示工作空间、执行引擎、Native 模型选择和任务输入；名称与 Worktree 位于“更多选项”。修改新会话默认设置后，尚未创建的普通草稿同步默认值，Native 已选择的模型连接与模型保持不变。
