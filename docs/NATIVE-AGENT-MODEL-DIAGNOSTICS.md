# Native 模型诊断与回归

模型请求失败现在保留有限枚举的协议、处理阶段和原因。历史仅有错误分类的记录仍可读取。诊断不保存模型错误正文、请求头、服务 URL 或凭据，也不根据失败自动切换协议。

三种适配器覆盖请求/响应头、消息开始、内容、thinking、工具调用和终态处理。错误原因包括无效历史、未配对工具调用、非法 JSON/事件顺序、无效 thinking/工具参数/用量、缺少终态、事件截断和连接中断。严格解析和有限重试的既有边界保持有效；收到部分输出的失败不会进入暂时 HTTP 错误重试。

## 缓存用量重新分类

真实 Kimi k3 转发服务可能在 `message_start` 将全部输入记为普通输入，随后在 `message_delta` 重新分类为缓存命中。例如普通输入从 213 变为 0，同时缓存读取从 0 变为 213。各分项减少不等于总输入减少。

解析器先原子合并本次用量，再检查非负安全整数、输出累计单调及包含缓存分项的总输入单调。允许合法缓存重新分类；总量下降、非法数值和不完整终态仍会被拒绝。相应用例覆盖工具续接及保存后重启。

## 真实服务回归

在已有包构建完成后运行：

```powershell
node scripts/native-model-regression.mjs --claude-config C:\Users\你的用户名\.claude\settings.json --model k3 --out C:\Temp\native-regression-新目录
```

脚本使用指定 Claude 配置中的现有 Anthropic 连接，凭据只在内存中读取；不会导入或改写应用配置。输出目录必须是新的目录，报告不可覆盖。工具仅返回隔离的随机测试值，不修改用户项目。

检查真实工具调用与下一轮响应、实际返回的 thinking 内容块、关闭/重开持久账本后续聊，以及重复提交的零额外请求。断流检查会刻意在真实服务 SSE 响应的首个完整事件后关闭流，验证完整终态缺失的诊断和重启后的失败回执去重。它属于真实连接上的故障注入，不宣称服务自然发生了断流。

报告仅包含模型 ID、测试结果、请求/工具计数、thinking 是否被观察到、有限枚举诊断和数值用量。原始账本保留在隔离输出目录，适用既有凭据内容检查。模型未返回 thinking 时只记录未观察到，不能据此宣称该服务已通过真实 thinking 验收。该回归也不替代固定工程任务质量对照或目标平台成品验收。
