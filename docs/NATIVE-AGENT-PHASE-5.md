正式运行验收统一见[独立清单](NATIVE-AGENT-RUNTIME-ACCEPTANCE.md)：真实服务、图形与当前候选三平台结果按稳定 ID 登记；本页保留实现说明与历史证据，不以旧候选通过替代当前验收。

本阶段交付可显式选择的 native 编码工作流，并建立和 Claude 对照的验收方式。Claude 持续保持默认。完成测试、评估或合并均不触发默认切换。

P4/P5 实现基线为 `dev/native-agent@59172f8`（PR #43）。后续[增量能力规划](NATIVE-AGENT-NEXT-PLAN.md)将任务闭环、检索与长任务作为优先交付，并准备真实工程任务评估；N1 现已实现，见 [N1 验收记录](NATIVE-AGENT-N1.md)。下述既有门槛保持有效，本地实现与测试不构成真实模型质量验收。

## 功能对照

| 工作流 | Native 当前能力 | 边界 |
| --- | --- | --- |
| 读代码、修改、验证 | 目录/读取/搜索、完整写入/精确编辑、命令与逐次审批 | 任意批准程序不是系统沙箱；命令和写入必须单独批准 |
| 用户交互 | 批准、拒绝、`ask_user` 选项或自由文本回答 | 回答只提供信息，不批准其他工具；过期、取消和陈旧回答不能生效 |
| 长任务 | 输入/输出/步数/主动时长预算、手动及可选发送前压缩 | 压缩可能丢细节；原始记录保留，实际服务窗口和费用不由预算保证 |
| 重启与中断 | 权威本地记录、重复提交回执、显式恢复、未知结果只读核查 | 不自动重放副作用、排队任务或旧审批 |
| 项目规范 | 分层 CLAUDE.md / AGENTS.md、显式项目 Skills、来源预览 | 同层 AGENTS 优先、深层优先、用户指令优先；不执行 frontmatter/hooks/imports |
| 模型与外部工具 | Responses / Chat Completions；三种已交付 MCP transport/version 组合 | 显式配置，无静默协议或引擎回退；详见各协议记录 |
| 并行工作目录 | 独立 worktree、宿主登记执行器之间的目录占用保护 | 不等于跨外部编辑器或所有 Git 操作的全局锁 |
| 队列与工作流 | 复用既有串行工作流、队列、审批、取消与所有权接口 | 首期不提供 native 多 Agent 并行或原生终端 |
| 跨引擎继续 | 预览并选择可见正文/手写摘要，创建新会话草稿 | 用户自行发送；不转移原引擎内部上下文、工具记录、附件或身份 |
| 用量与成本 | 服务用量、显式模型价格、本回合价格快照估算 | 不完整用量或模型不匹配保持未知；压缩、缓存差价及附加费用另计 |

原生终端、附件、Claude 内部历史导入/分叉、运行中配置、完整全局/插件 Skills 和所有 MCP 可选扩展仍未支持。它们不是本期已经承诺的全面 Claude CLI 兼容；评估中若日常任务确实依赖，应记录为能力差距，另行排期。不能将入口可选与“已达到同等质量”混为一谈。

## 固定任务及预先约定的门槛

使用[固定任务工具](NATIVE-AGENT-EVALUATION.md)，缺陷修复、小功能补测、嵌套双指令重构各一项；每个待评估引擎在独立副本执行相同任务，至少重复两轮。每轮从固定基线重新准备，记录应用提交、引擎/模型/协议、配置、实际 diff、验证退出码、服务用量、耗时和人工介入。用量未知须保留未知。

功能候选通过标准：每项独立验收检查和用户要求的测试通过，项目指令和原测试未被绕过，无越权或未经批准的修改/命令，无结果未知却自动重试的操作；人工复核差异属于任务范围且没有遗留阻塞缺陷。至少两轮均满足才可登记此模型/配置下的固定任务通过，不能推及所有模型。

稳定性门槛：取消、拒绝、审批失效、断流、重启恢复、重复提交、磁盘失败、工具清理和队列所有权回归通过；Electron 界面与实际目标平台成品另行验证。速度、token 与费用只比较有可靠记录且同任务、同范围的结果，不因缺失数据默认给出零成本或优势结论。

真实模型测试必须先明确服务、模型、凭据来源及预算。当前环境可验证本地协议 fixtures 和评估工具自身，不能据此认定真实模型任务通过。图形环境和三平台验收、真实模型对照仍保持待执行；其结果登记到[交付清单](NATIVE-AGENT-COMPLETION.md)。
