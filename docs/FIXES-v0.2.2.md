# v0.2.2 修复与验收对照

更新日期：2026-09-21。对应《cc-desk v0.2.0 后续优化检查》的 R01–R22。下表区分已实现的代码、已有回归证据和仍待目标平台验证的范围；新增测试不代表已完成真实模型或安装包验收。

## 回复重复：本次维护版的重点

新回合统一协调 `stream_event`、完整 `assistant` 和 `result`：按照回合、主任务/子任务、消息身份、内容块及完成事件 UUID 归并。覆盖普通短回复、完成事件缺少 API 消息 ID、重复事件、多文本块、流式块与完成事件交错，以及超过 262144 字符的回复。结果摘要按截断前的内容指纹比较；不同回合、不同消息或不同内容块中合法的相同文本继续保留。超长正文显示省略提示，可通过记录导出查看保留的完整内容。

升级时会重建旧版聊天投影，并仅清理日志能够证明的旧重复：成功 `result` 紧接着生成的同回合 UUID 助手条目，与此前规范主任务消息的完整正文或多块摘要一致。原始 journal 不改写。缺少来源证据、身份不明确、子任务、不同回合或错误摘要等旧记录保留，不以全局文本相同为由删除。此次修复覆盖的协议场景已用本地子进程复现；没有取得用户原始故障日志，不能断言其每一条历史重复都来自同一原因。

## 验证结果与平台边界

本地完整单元/集成测试共 **128 项：127 通过、1 项 Windows 专用测试跳过、0 失败**；其中包括聊天/恢复 37 项及 renderer 4 项。桌面 E2E **2/2 通过**，TypeScript 检查和生产构建通过。完整运行记录以 [VALIDATION.md](VALIDATION.md) 为准。协议验证使用本地 fixture；未发送付费模型请求，也未据此宣称真实模型、真实中文输入法或 OS 通知已验收。

R06 的新增门禁覆盖计划如下。代码已接入 CI，**本版本各平台的原生打包执行结果仍待 CI 产出**：

| 平台 | 门禁实际启动的发行载荷 | 保留的边界 |
|---|---|---|
| Windows x64 | NSIS 安装后的程序、解压 ZIP 中的程序 | 另行发布的自解压 portable EXE 包装器未执行；签名与 SmartScreen 接受情况未验证。 |
| macOS arm64 | 从 DMG 复制出的 `.app`、解压 ZIP 中的 `.app` | 未完成签名/公证和 Gatekeeper 接受验证；不覆盖 Intel。 |
| Linux x64 | 从 AppImage 提取的程序、解压 tar.gz 中的程序 | 不覆盖 FUSE 挂载及通过 FUSE 直接启动 AppImage。 |

这些测试验证当前包重启及旧版可选字段缺失时的数据兼容；不等同于所有历史版本的覆盖安装升级、回滚或真实用户数据迁移验收。发行仍不具备 Windows 代码签名或 macOS 签名/公证保证。

R14 在 Linux 使用描述符锚定路径并核验实际句柄位置；macOS/Windows 当前使用打开前、打开后及读取后的文件/祖先身份检查。它能检测已覆盖的替换场景，但不能宣称阻断恶意进程精确配合的全部 ABA（替换后又恢复）竞态。更强的跨平台保证仍需原生目录句柄及最终路径接口。
