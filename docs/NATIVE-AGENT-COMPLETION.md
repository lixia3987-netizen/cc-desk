## 兼容与复核

第二协议、价格配置和自定义 Skills 路径需使用支持这些字段/路径的版本。旧版本可能拒绝新连接元数据或选择，不应删除记录强行降级。已有 Responses 会话保留其协议、服务和模型绑定；修改这些字段需要新会话，价格修改只影响后续运行。

独立复核已完成，已修复并回归两处边界：提问等待期间项目指令/所选 Skill 改变后拒绝旧回答；失败请求没有用量回执时不使用先前部分用量估算整回合费用。评估器还校验原测试/指令不变及新增回归文件，并原子写出报告。

实现说明：[Chat Completions](NATIVE-AGENT-PHASE-4C-CHAT-COMPLETIONS.md)、[用户提问](NATIVE-AGENT-P5-QUESTIONS.md)、[P5 能力对照与门槛](NATIVE-AGENT-PHASE-5.md)、[固定任务评估](NATIVE-AGENT-EVALUATION.md)。
