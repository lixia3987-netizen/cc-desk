# P4 / P5 剩余交付与验收清单

基线：`dev/native-agent@0bec633`（PR #42 已合入）。2026-09-28 用户要求自动拆分并完成已规划剩余内容，关键修改分批提交。本清单将总计划中尚未细化的条目落实为可验证交付，不扩大为所有 Claude CLI 或所有 MCP 可选能力的兼容承诺。

| 规划项 | 本期交付 | 状态 |
| --- | --- | --- |
| P4c 模型协议扩展 | 显式选择 Chat Completions；完整文本/工具/用量/取消链路，协议独立的恢复和压缩 | 开发中 |
| P4c Skills / 指令管理 | 额外项目相对 SKILL.md 的显式选择；正文、来源和适用项目指令检查 | 开发中 |
| P4d 连接与成本 | 用户自行填写具体模型价格；按服务用量和运行价格快照估算；历史价格不漂移 | 开发中 |
| 首版提问交互 | 自研 Agent 的用户提问工具，复用明确答复与取消边界 | 待实现 |
| P5 跨引擎继续 | 新会话显式导入可见消息为草稿，不复制引擎私有上下文，不自动发送 | 开发中 |
| P4d / P5 固定任务评估 | 可重复任务、结果记录和质量门槛；本地协议/回归与真实模型效果分开记载 | 待实现 |
| 实际验收 | 用户指定真实服务、模型、凭据来源、预算；Electron 图形及三平台成品检查 | 待外部条件 |

已集成的 MCP HTTP 2026、Streamable HTTP 2025 和 stdio 2025 同步工具闭环完成本期工具接入。旧 HTTP+SSE、OAuth、resources/prompts、sampling、elicitation、tasks 等是未支持的协议扩展，不属于已确定的首期工具接入验收。全局自动 Skills、插件市场、原生终端、多 Agent 并行同样不在本期交付内。额外模型协议采用显式选择，不根据失败自动降级。

始终保持 Claude 默认引擎。仅合入 `dev/native-agent`，不修改 main、不发布 Release、不触发 CI。功能实现与本地测试通过不能替代真实模型质量评估，也不构成切换默认引擎的授权。

各实现批次完成后补充本文件中的实际命令、结果和限制；未执行的项目保持待验收。
