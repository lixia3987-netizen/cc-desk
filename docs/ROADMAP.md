# 开发进度与剩余路线

当前源码进度为 v0.2.3，已实现可靠性修复、本地图形化开发流程、顺序工作流、只读诊断及五套主题。以下区分代码实现与外部环境验收；最新操作问题、复现步骤及验收标准见 [v0.2.3 体验检查](UX-REVIEW-v0.2.3.md)。

## 已实现

- 每会话独立自动保存主输入、工作流及按文件审阅草稿，恢复选择、附件隔离及跨重启恢复、快捷切换。
- 体验检查 UX01–UX09 已完成本地修复和回归：阅读位置、默认项目、终端误报、模板追加、CLI 检测及 Git 刷新等；详见 [第一轮修复记录](UX-FIXES-round1.md)。
- 已完成会话内查找/消息定位、旧消息分页、跨会话历史阅读恢复和统一有效审批/提问入口；详见 [第二轮记录](UX-FIXES-round2.md)。
- 五套差异明显的主题、即时预览、保存及重启恢复；终端同步换色。
- CLI 检测与认证/配置诊断分离；不将可执行文件存在称为已连接模型。
- 项目优先的历史分页/全文搜索；完整原始 JSONL 导出与滚动日志区分。
- 有界终端和消息缓存；原子持久化、取消、退出清理。
- 结构化双向协议、流式消息、工具与问题卡片、单次审批、任务状态、用量。
- 空闲回合间更新模型/权限，强度修改需重启，保持 CLI 确认语义。
- 文件检索/预览、@引用、原生附件选择；图片/PDF 按类型送入模型。
- 文件级 Git diff 和审阅意见；有所有权和目录锁的 Worktree 快进合并、保守清理。
- MCP/Skills/config/provider 只读清单，结构化会话报告的 MCP 状态。
- 真实回合结果驱动的持久化顺序工作流、依赖、摘要、阶段确认、手动重试、取消及恢复。
- 通知、托盘和命令面板；macOS PTY helper 安装修复；打包禁用隐式发布。

## 已实现但仍需实机/账号验收

- Windows/macOS 原生 CLI、多平台中文 IME、目录信任、真实权限和认证错误。
- 真实 provider/模型下的长任务、子代理、MCP 认证、恢复和分支对话。
- PTY hooks 在用户/组织设置允许的环境中的身份与模型同步。
- 通知与托盘在各桌面系统中的实际行为。

详见 VALIDATION.md；协议 fixture 的成功不能替代真实账号调用。

## 下阶段

1. 每会话未读计数、可调整面板、聊天字号、截图粘贴及拖放、整条消息复制/引用和 Markdown 导出。
2. 首次连接与故障恢复、项目/会话整理、诊断导出及备份恢复、版本检查；拆分日常校验与发行打包，保留正式发布的原生验收门槛。
3. MCP 配置编辑、作用域差异、启动健康检查和日志；Skills/插件启用管理。当前只读诊断不冒充管理器。
4. 完整子任务树、可验证阶段产物与验收规则；当前工作流按回合结果和摘要追踪，不自动证明任务目标完成。
5. Git 冲突编辑、三方合并、逐行定位与外部编辑器跳转；当前自动合并仅快进，分叉需手动处理。
6. 按实际规模推进持久化全文索引、增量更新和虚拟列表；具备证书和发布配置后增加签名、安装升级与回滚验证。

## 按需扩展

开发服务器和浏览器预览、PR/CI 面板、WSL/SSH 与路径映射、远程访问、定时任务。每项需独立明确运行环境和验收，不与本地会话实现混为一体。
