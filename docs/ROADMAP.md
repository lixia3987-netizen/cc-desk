# 开发进度与剩余路线

本轮从 v0.1 升级到 v0.2，优先交付可靠性和本地图形化开发流程，并提前接入顺序工作流与只读诊断。以下区分代码实现与外部环境验收。

## 已实现

- 每会话独立自动保存草稿、恢复选择、附件隔离、快捷切换。
- CLI 检测与认证/配置诊断分离；不将可执行文件存在称为已连接模型。
- 项目优先的历史分页/全文搜索；完整原始 JSONL 导出与滚动日志区分。
- 有界终端和消息缓存；原子持久化、取消、退出清理。
- 结构化双向协议、流式消息、工具与问题卡片、单次审批、任务状态、用量。
- 空闲回合间更新模型/权限，强度修改需重启，保持 CLI 确认语义。
- 文件检索/预览、@引用、原生附件选择；图片/PDF 按类型送入模型。
- 文件级 Git diff 和审阅意见；有所有权和目录锁的 Worktree 快进合并、保守清理。
- MCP/Skills/config/provider 只读清单，结构化会话报告的 MCP 状态。
- 真实回合结果驱动的持久化顺序工作流、依赖、摘要、阶段确认、手动重试、取消及恢复。
- 通知、托盘和命令面板；macOS PTY helper 安装修复；打包禁用隐式发布。

## 已实现但仍需实机/账号验收

- Windows/macOS 原生 CLI、多平台中文 IME、目录信任、真实权限和认证错误。
- 真实 provider/模型下的长任务、子代理、MCP 认证、恢复和分支对话。
- PTY hooks 在用户/组织设置允许的环境中的身份与模型同步。
- 通知与托盘在各桌面系统中的实际行为。

详见 VALIDATION.md；协议 fixture 的成功不能替代真实账号调用。

## 下阶段

1. MCP 配置编辑、作用域差异、启动健康检查和日志；Skills/插件启用管理。当前只读诊断不冒充管理器。
2. 更大规模历史的持久化全文索引与后台增量更新；附件草稿跨重启恢复、原生拖放、截图粘贴。
3. 完整子任务树、可验证阶段产物与验收规则；当前工作流按回合结果和摘要追踪，不自动证明任务目标完成。
4. Git 冲突编辑、三方合并、逐行定位与外部编辑器跳转；当前自动合并仅快进，分叉需手动处理。
5. 可调整面板、主题、后台独立进程、日志保留策略和诊断导出。
6. 具备证书和发布配置后增加签名、安装升级与回滚验证。

## 按需扩展

开发服务器和浏览器预览、PR/CI 面板、WSL/SSH 与路径映射、远程访问、定时任务。每项需独立明确运行环境和验收，不与本地会话实现混为一体。
