# 第一轮体验修复：连续输入与会话切换

日期：2026-09-22。对应 [体验检查](UX-REVIEW-v0.2.3.md) 中的 UX01–UX09，纳入尚未发布的 v0.2.3 源码。

## 已完成

| 编号 | 修复后的行为 |
| --- | --- |
| UX01 | 只为结构化会话读取附件；切换到 Claude 原生终端或 Shell 不再误报图形化会话错误，过期附件请求的结果和错误被忽略。 |
| UX02 | “添加完整开发提示词”追加到现有草稿。超过草稿容量时明确提示并保留已有输入；审阅意见同样只在成功追加后清理。 |
| UX03 | 工作流目标、暂停选项、尝试次数、记录筛选和未提交阶段指令按会话保存。切换页签、切换会话及重启后恢复；成功创建或保存只清理对应且未被再次修改的草稿。 |
| UX04 | Git 审阅意见按会话及文件分别保存，选中文件和暂存视图一起恢复。刷新后文件不再有变更时提示状态变化，仍保留意见。 |
| UX05 | 普通新建依次使用有效的项目筛选、当前会话项目、首个项目；分支创建始终使用来源项目，来源不存在时不回退到其他项目。 |
| UX06 | 切换长对话时恢复可见消息及其偏移，调整窗口宽度后维持阅读锚点；“跳到最新”恢复跟随。阅读位置保存在当前应用进程中，本轮未加入跨重启的阅读位置恢复。 |
| UX07 | “重新检测”改为“保存并检测”，先保存当前设置再检测；路径未变时也可重新探测。提示未保存路径、显示检测路径，探测期间隐藏旧结果；修改路径不会重复启动两次探测。 |
| UX08 | 结构化会话的“准备会话”改为“开始输入”，聚焦编辑器并提示首条任务发送后启动，不发送空模型请求。 |
| UX09 | Git 在结构化回合结束、可观察到的终端完成/退出及窗口重新聚焦后刷新，显示更新时间。使用即时聊天事件携带的任务状态，避免快速回合被批量状态更新跳过；过期查询结果不覆盖新结果。 |

工作流和审阅草稿写入现有工作区原子存储，采用可选字段兼容旧数据。编辑立即发送到主进程，磁盘写入合并，退出时刷新；IPC 校验草稿大小和条目数量。删除会话同时删除其面板草稿。

## 验证结果

- 完整 Node 单元/集成测试：136 项，135 通过，1 项 Windows 专用测试在 Linux 跳过。修正快速回合刷新后，再次执行 SessionService 相关 10 项，全部通过。
- TypeScript 与生产构建通过；最终 Electron 桌面测试 6/6 通过。
- 新增 3 组桌面回归：工作流与按文件审阅草稿切换/重启、编辑后立即退出、项目筛选与分支默认值、已删除项目回退、阅读锚点与窗口缩放、模板追加、三种会话切换、两个不同版本 npm CLI 探针以及同路径重新检测。
- 原有真实协议子进程回归新增“修改文件 → 快速结束回合 → Git 自动刷新”，同时断言选中文件和审阅草稿不丢失；真实 Shell、审批、问答、工作流及五主题回归保持通过。
- 已检查更新后的 [设置界面](themes/settings.png) 和 [Git 审阅界面](screenshots/structured-chat.png)。

本次使用 Linux Electron、真实本地 Shell 和隔离 CLI 测试进程，没有调用收费模型。Windows/macOS 原生安装、真实账号、中文输入法及本轮正式安装包尚未验收。GitHub Actions 的账号付款/支出限制仍阻止远程发行，不跳过原生发布门槛。
