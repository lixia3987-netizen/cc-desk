## 项目指令兼容性调整

2026-09-28 起，项目指令同时支持 `CLAUDE.md` 与 `AGENTS.md`。从授权项目/worktree 根到目标目录逐层加载，每层先加载 `CLAUDE.md`、再加载 `AGENTS.md`；深层目录优先，同层冲突以 `AGENTS.md` 为准，用户明确指令优先于项目文件。

两种文件共用原有单文件 32 KiB、合计 128 KiB 限制，不额外扫描 HOME 或 `.claude` 目录作为全局指令来源，也不执行 URL/include 导入；目标位于项目内 `.claude` 时仍适用一般逐层规则。指令来源、作用域与内容哈希参与审批绑定，任一适用指令变化均使旧审批失效。此扩展不等于完整 Skills/多来源指令管理已完成；本节不沿用历史候选的通过结果作为新增代码验收。

## P4a 范围

### 增量文本编辑

新增 `edit_file({path, expectedHash, oldText, newText})`：在指定完整文件版本上替换唯一精确匹配的片段。允许 `newText` 为空以删除片段；拒绝空匹配、多处匹配（包括重叠）、无变化、非法文本和超限内容。不做模糊匹配或隐式全局替换。

沿用文件路径身份检查、完整 SHA-256、适用项目指令、逐次审批和原子写入；当前项目指令包括上述 `CLAUDE.md` 与 `AGENTS.md`。审批绑定原始参数与版本，批准后再次验证文件、规则和目录所有权。已有 `apply_patch` 保持创建/完整替换语义。

### 上下文预算与用量

显示下一次请求的保守输入估算、已配置输入预算、上下文字节预算和接近/达到限制状态。服务返回的最近一次输入 token 与回合累计用量单独标识；缺失数据保持未知。

会话与引擎默认设置提供输入预算、单次输出上限、每回合模型请求次数和工具调用次数的整数配置。运行时锁定，停止后修改于下一回合生效；空值、非整数和越界值不覆盖有效配置。

运行预算不是模型上下文窗口，估算不是服务计费。估算口径与现有核心限制一致：历史、项目指令与工具定义的 UTF-8 字节；这仍不等于服务端 token 计数，不能承诺一定落在远程模型窗口或费用内。P4b 已增加默认关闭的发送前自动压缩，不删除原始记录或重放工具。价格估算和新增协议的当前状态见剩余交付清单。

### 显式连接诊断

仅由用户对已保存连接点击测试，提前说明可能计费。发送一个固定、小型、无工具的 Responses 流式请求，无自动重试；普通列表和就绪检查不发送网络请求。

诊断有超时、主动取消、窗口销毁与退出收尾；运行期间锁定连接修订，避免修改认证或地址后混用结果。仅返回白名单状态、耗时和实际用量，不返回模型输出、响应原文、URL、密钥或请求头。通过只说明该模型完成了本次文本协议响应，不代表工具调用、长任务或全部兼容服务已验证。
