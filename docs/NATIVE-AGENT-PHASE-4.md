## P4a 范围

### 增量文本编辑

新增 `edit_file({path, expectedHash, oldText, newText})`：在指定完整文件版本上替换唯一精确匹配的片段。允许 `newText` 为空以删除片段；拒绝空匹配、多处匹配（包括重叠）、无变化、非法文本和超限内容。不做模糊匹配或隐式全局替换。

沿用文件路径身份检查、完整 SHA-256、适用 AGENTS.md、逐次审批和原子写入。审批绑定原始参数与版本，批准后再次验证文件、规则和目录所有权。已有 `apply_patch` 保持创建/完整替换语义。

### 上下文预算与用量

显示下一次请求的保守输入估算、已配置输入预算、上下文字节预算和接近/达到限制状态。服务返回的最近一次输入 token 与回合累计用量单独标识；缺失数据保持未知。

会话与引擎默认设置提供输入预算、单次输出上限、每回合模型请求次数和工具调用次数的整数配置。运行时锁定，停止后修改于下一回合生效；空值、非整数和越界值不覆盖有效配置。

运行预算不是模型上下文窗口，估算不是服务计费。估算口径与现有核心限制一致：历史和项目指令的 UTF-8 字节，不含工具定义与协议封装，因此不能承诺一定落在远程模型窗口或费用内。未配置或未验证价格时不估造费用。当前不自动压缩、删除历史或重放工具；停止原因提供可执行的说明。

### 显式连接诊断

仅由用户对已保存连接点击测试，提前说明可能计费。发送一个固定、小型、无工具的 Responses 流式请求，无自动重试；普通列表和就绪检查不发送网络请求。

诊断有超时、主动取消、窗口销毁与退出收尾；运行期间锁定连接修订，避免修改认证或地址后混用结果。仅返回白名单状态、耗时和实际用量，不返回模型输出、响应原文、URL、密钥或请求头。通过只说明该模型完成了本次文本协议响应，不代表工具调用、长任务或全部兼容服务已验证。

## 验证要求

- 文件工具：真实修改、重复/重叠匹配、版本冲突、批准后变更、规则变化、取消、大小边界；拒绝时原文件保持不变。
- 上下文：与核心停止条件一致，估算/实测区分，缺失用量与回合切换，重启从权威账本重建，Claude 显示不退化。
- 连接：本地真实 HTTP/SSE 成功、错误分类、无内容/错误协议、超时取消、修订与并发锁、渲染器生命周期；敏感哨兵不得出现在结果或磁盘。
- 桌面：正式 IPC/worker 的编辑审批及预算展示、诊断 UI；最终候选执行根检查、三平台源码 E2E 与实际成品测试。
