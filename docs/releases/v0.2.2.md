# Claude Workbench / cc-desk v0.2.2

修复部分回复在界面显示两次的问题，并落实此前检查报告中的可靠性、历史、附件、Worktree 和交互修复。

## 回复重复与恢复

- 流式片段、完整 assistant 消息和最终 result 按轮次、消息 ID、文本块和子任务来源归并，覆盖多段回复、缺失 ID、重复事件及长回复。
- 不同轮次或不同消息中相同的正常回复会保留。超长显示内容明确标记省略，完整事件日志可导出。
- 恢复快照后回放尚未投影的日志；安全修正旧日志能够证明的重复 result。缺少来源依据的旧重复记录保留，避免误删。CLI 原始历史不改写。
- 外部 CLI 续聊只在记录稳定且身份锚点匹配时补入。

## 其它修复

- 保存失败也会停止子进程，退出等待进程树清理；磁盘恢复后可以重试保存退出。后台任务按无进展时间超时，人工审批/问答等待不误触发。
- 修复 2048 条以上历史文件缓存抖动；减少流式重复计算、无变化状态写入和频繁广播。
- Worktree 清理检查子目录占用、路径别名及衍生会话依赖；仓库变更串行执行。重命名 diff 同时比较旧、新路径；诊断使用实际会话目录。
- 标准 Markdown、代码复制/高亮、表格和安全链接；输入法组合期间不触发发送。审批草稿切换会话保留，模态框约束键盘焦点，通知可定位被筛选或归档的会话。
- 附件保留原名和大小，草稿重启恢复，移除未引用副本可回收，支持纯附件发送；发送失败保留草稿。已被对话引用的文件不会被误删。
- 工作流历史可导出、删除并回收容量；删除会话同步清理非活跃记录。
- 保留 Windows npm CLI 新旧入口兼容性；补齐 macOS/Linux GUI PATH 缺少 nvm Node 的明确 CLI 路径启动。二次启动可恢复托盘隐藏窗口。

完整编号对照见 [v0.2.2 修复清单](https://github.com/lixia3987-netizen/cc-desk/blob/v0.2.2/docs/FIXES-v0.2.2.md)。

## 下载与更新

Windows x64 提供 `setup.exe` 安装版、`portable.exe` 单文件便携版和 `portable.zip`；macOS Apple silicon 提供 arm64 DMG/ZIP；Linux x64 提供 AppImage/tar.gz。文件名均包含 `0.2.2`，附 `SHA256SUMS.txt`。

完全退出旧版（包括托盘实例）后安装或运行新版；默认用户数据目录不变。无需删除原会话，也无需重装已正常工作的 Claude Code。便携包默认仍使用用户数据目录。

## 验证范围

发布门禁覆盖三平台类型检查、回归测试、桌面交互、打包，以及真实发布载荷的启动、PTY、退出、旧格式数据重启和第二实例恢复。Windows 验证 NSIS 静默安装后的程序与 ZIP；macOS 验证 DMG 复制后的程序与 ZIP；Linux 验证 tar 与提取的 AppImage。实际结果见本 Release 的构建记录。

包尚未签名/公证；Windows 便携 EXE 的自解压启动器、Linux FUSE 挂载、系统安全提示、真实中文输入法及已登录模型调用仍需实机验收。文件预览已加强路径竞态检查，macOS/Windows 对恶意并发目录反复替换的完整防护仍需要原生目录句柄支持。测试不会发起收费模型请求或改写用户 Claude 配置。
