# Claude Workbench / cc-desk v0.2.0

封装本机 Claude Code CLI 的独立桌面工作台，支持 Windows、macOS 和 Linux，提供中文界面。

## 下载与启动

请在本页 Assets 下载对应文件；无需从 GitHub Actions 下载整个构建记录。

| 系统 | 文件 | 使用方式 |
| --- | --- | --- |
| Windows x64 | `cc-desk-0.2.0-windows-x64-setup.exe` | NSIS 安装程序，可选择安装目录 |
| Windows x64 | `cc-desk-0.2.0-windows-x64-portable.exe` | 单文件便携版，直接运行，启动时解压至临时目录 |
| Windows x64 | `cc-desk-0.2.0-windows-x64-portable.zip` | 解压完整目录，运行其中的应用程序 |
| macOS | `cc-desk-0.2.0-macos-<arch>-setup.dmg` | 打开后将应用复制到 Applications |
| macOS | `cc-desk-0.2.0-macos-<arch>-portable.zip` | 解压后运行 `.app` |
| Linux x64 | `cc-desk-0.2.0-linux-x86_64-portable.AppImage` | 增加执行权限后运行，无需系统安装 |
| Linux x64 | `cc-desk-0.2.0-linux-x64-portable.tar.gz` | 解压完整目录，运行 `claude-workbench` |

macOS 架构以 Assets 实际文件名为准：`arm64` 对应 Apple silicon，`x64` 对应 Intel。本次构建沿用 macOS runner 的架构，未声明提供通用二进制。Linux 的两个格式都是免安装包，没有 `.deb` 或 `.rpm` 系统安装器。

“便携版”仅指免安装；会话、附件与设置仍默认保存在 Electron userData 目录，准确路径显示在设置中。移动可执行文件不会迁移这些数据。ZIP 和 tar.gz 中的依赖必须随程序一起保留。

`SHA256SUMS.txt` 提供各安装包、便携包的 SHA-256 校验值。

## 本版功能

- 结构化对话、流式回复、工具输入与结果、图形化审批和问答。
- 项目与会话管理、独立草稿、历史搜索与恢复、附件和文件引用。
- Git 文件差异审阅、Worktree 创建、快进合并与清理。
- CLI、认证、MCP 和 Skills 诊断；持久化分阶段工作流。
- 原生 Claude 终端与 Shell、任务通知和托盘。

## 使用条件与已知边界

- 先在本机安装并登录 Claude Code CLI，再到“设置与连接”检测或指定 CLI 路径。客户端不附带 CLI、模型服务或账户额度。
- 模型调用、工具和权限由本机 CLI 提供；CLI 协议兼容性可能随版本变化。
- 安装包和便携包尚未签名或公证，系统可能显示来源提示。当前没有自动更新，升级请重新下载。
- 便携包沿用相同应用身份和默认用户数据目录；切换安装版与便携版时先退出正在运行的实例。
- 真实 Claude 账户调用、中文输入法等仍需实机验收；MCP/Skills 目前提供诊断清单，未提供完整配置管理。
