# cc-desk v0.4.0

本版整合自 v0.3.0 以来的字体、上下文与命令、CLI 更新功能，并修复上下文报告后继续对话丢失占比的问题。现有 Claude Code 与 Shell 执行路径迁入公共接口，保留会话恢复、审批、工作流和原生终端。

## 字体与设置

- **读取系统字体**：聊天与菜单分别选择本机已安装字体，支持搜索、刷新、即时预览、取消恢复和保存后重启保留。字体列表只在本机使用，不复制系统字体文件。
- **独立字号与字体导入**：聊天字号 11–28 px，菜单基准字号 11–20 px；支持 TTF、OTF、WOFF、WOFF2，保存应用内副本。终端字号保持独立。
- **分类设置**：左侧分为外观与字体、连接与终端、会话与权限、工作区与 IDE、通知与后台；切换分类保留未保存输入。
- **移除 Fontsource**：删除全部 `@fontsource-variable/*` 依赖和预置字体资源，聊天与菜单默认使用系统字体，代码使用系统等宽字体。需要指定字体时选择系统已安装字体或自行导入。

使用方法见[字体说明](https://github.com/lixia3987-netizen/cc-desk/blob/v0.4.0/docs/FONTS.md)。

## Context、命令与 Skills

- 输入区显示最近一次主会话请求的输入 token、CLI 报告的窗口容量与占比；展开查看模型、更新时间和压缩记录。缓存读取 / 写入计入输入用量，累计请求和子任务用量不叠加为当前上下文。
- 输入 `/` 搜索当前会话提供的系统命令与 Skills，支持方向键、Enter / Tab 填入、参数编辑和 Esc 关闭。读取列表不发送模型请求；项目、用户及插件 Skills 由 CLI 加载。
- `/context` 查看详细分布，`/compact` 主动压缩，`/clear` 切换到新 CLI 上下文并保留工作台已有聊天记录。终端专用命令仍需在原生终端执行。
- **修复持续刷新**：报告模型展示名称与实际请求标识不同、后续结果没有 `modelUsage`，均不会让已知容量消失。普通对话继续更新输入用量；缺失用量保留上次有效读数，停止 / 重启也保留。确认模型变化或 `/clear` 后清除旧读数，压缩完成后等待下一次请求更新占比。

## 确认后更新 Claude Code CLI

每次启动在后台检查选定 CLI 的版本；发现更新可选择更新或暂不更新，也可在设置中手动检查。

更新前必须在原生窗口中确认：**全部工作区**的聊天、Shell、工作流和子进程都将停止。应用等待停止与保存成功后才执行更新，任一步失败都会取消。项目、worktree、历史与草稿保留；更新结束后由用户手动恢复任务。更新命令结束后重新检测实际版本，未升级不会显示成功。

此功能更新本机 CLI，cc-desk 桌面应用自身仍需手动升级。安装方式与已知网络限制见 [CLI 更新说明](https://github.com/lixia3987-netizen/cc-desk/blob/v0.4.0/docs/CLI-UPDATES.md)。

## 执行架构与桌面回归

- 提取公共会话身份、结构化 / 终端执行接口、归一化事件和功能能力声明；会话编排通过注册表使用 Claude 与 Shell 适配器。当前产品仍使用这两条执行路径，没有新增其他模型后端。
- 拆分 CLI 连接、流式投影、协议处理、历史恢复、IPC 和工作台组件，减少单文件职责；保持本地会话 ID 与后端对话 ID 分离。
- Linux 桌面测试统一使用真实 X11 窗口，无 `DISPLAY` 时由入口自动启动 Xvfb。移除会导致当前 Electron 普通窗口在创建阶段崩溃的 Ozone headless 回退；安装包测试与截图脚本使用相同显示要求。
- 修复 Windows 静默终端关闭后遗留 ConPTY 转发线程的问题，更新与退出会等待终端资源释放。macOS 进程组仅剩僵尸进程时，查询进程表确认无存活成员后才接受关闭；真实权限或查询错误仍阻止更新。
- 终端进程退出后保持“正在停止”，直到进程树与附加资源全部释放再显示“已停止”，避免界面允许归档时后台仍拒绝操作，以及停止后立即退出仍弹确认的时序问题。
- 小窗口中同时显示 CLI 更新提示和展开的子任务详情时，详情列表在面板内滚动，保留完整输入区与操作按钮。

完全退出旧版（包括托盘）后安装或解压新版本，数据目录不变。“便携”指免安装，数据仍默认保存在本机应用数据目录；GitHub 的源码压缩包不是桌面应用。

工作区元数据升级为版本 2，读取旧版本时迁移会话身份，保留本地会话 ID、历史、草稿、选中状态和 worktree 路径。升级前可备份设置中显示的数据目录；旧版不能直接读取新格式，回退时需使用升级前的数据副本。原预置 Fontsource 字体不再随包提供。

## 验证与已知边界

发布流程要求三平台检查、桌面测试、打包及实际包启动验证成功后上传资源。**具体执行结果以本 Release 附带的源提交和 Actions 记录为准**，开发验证详见[验证记录](https://github.com/lixia3987-netizen/cc-desk/blob/v0.4.0/docs/VALIDATION.md)。本地协议与 PTY 回归不代表真实 Claude 账户、全部 CLI 版本或模型服务均已验收。

- Claude `settings.json.env` 中的代理尚未转发给应用的更新检查；会话正常不保证更新元数据可达，本版未修复这项限制。检查失败不影响现有会话，也不会开始安装或断开工作区。
- 包未签名 / 公证，macOS 仅提供 Apple silicon arm64。Windows 单文件便携启动器、Linux FUSE 挂载和真实系统安全提示仍需实机验收。
- 使用前需安装并登录本机 Claude Code CLI；cc-desk 不是 Anthropic 官方产品，不附带模型服务或账户。
