# cc-desk v0.5.1

本版整合 v0.5.0 之后的会话命名、Worktree、附件与界面更新，并修复清空上下文后无法恢复及损坏 Worktree 删除受阻的问题。继续使用本机 Claude Code CLI，沿用已有账号、代理和模型配置。

## 会话命名与连接管理

- 新建会话名称留空时，首条有效消息由独立 agent 异步总结标题，不再截取消息原文。命名请求禁用工具与 MCP，不加入聊天历史；失败或超时保留默认名称，不阻塞正常对话。手动名称、导入及分支会话保持不变。
- 点击底部「已连接」可查看所有项目的当前连接，包括等待下一轮输入和正在关闭的会话，不受侧栏筛选影响。支持跳转到会话，以及关闭指定连接；关闭会停止对应任务和工作流、暂停剩余队列，保留记录与草稿。
- 工程筛选同时显示名称和路径，超长路径省略，悬停查看完整路径；支持同名项目区分和键盘选择。
- 移除消息发送后持续显示的「消息已接收，正在执行」提示，保留聊天内容、真实执行状态、待发送队列及错误反馈。
- 修复删除或切换会话后，旧聊天刷新请求的迟到错误仍显示在界面的问题；删除失败后会恢复该会话的自动刷新。

自动命名会额外发起一次模型请求，沿用 CLI 默认模型或会话显式指定的模型。旧 CLI 缺少必要隔离参数，或原生终端无法提供已接受消息的 hook 时，保留默认名称。

## Worktree 创建与删除

- 创建时可选择本地或远程分支作为起点。远程列表支持刷新，创建前再次获取所选远程分支的最新提交；获取失败时不会使用陈旧缓存继续创建。
- Worktree 名称留空时使用随机短 ID，不再使用会话名称；仍可填写自定义名称。创建不会切换主项目分支，也不会带入未提交修改。自动合入目标仍是创建时来源目录所在的分支。
- 删除会话可选择「仅删除会话，保留隔离目录」，保留目录中的全部文件和 Git 分支。安全清理被阻止时会显示原因及路径；没有新增提交的干净工作区也可安全清理。
- 新增「删除会话并强制删除隔离目录」，需要再次核对路径并输入「删除」。支持处理可验证归属的 `.git` 缺失或目录已不存在等情况；归属不明、被占用或存在依赖时保留文件并反馈原因。

强制删除会丢弃隔离目录中的未提交、未跟踪和被忽略文件；Git 分支、已提交内容及来源项目保留。请在确认前检查需要保留的文件。

## 右侧面板布局

右侧采用常驻竖向工具栏，「上下文 / 变更 / 工作流 / 诊断」可同时打开，独立关闭，按打开顺序优先上下排列：一个面板占整列，两个上下排列；空间足够时，第三个在右侧占整列，第四个再分割右列，两列等宽。窄窗口保持单列滚动。

全部关闭后保留工具入口并让出聊天空间；面板内按 Shift+Esc 关闭当前面板。打开状态与顺序在本机保存，兼容旧版布局设置。开关或调整布局保留当前会话的未保存输入，不重启终端。新版不再提供面板标题折叠及整体收起按钮。

## 附件与上下文恢复

- 可将本地文件拖入结构化对话区或输入框，加入待发送附件。拖放只保存副本，不自动发送或改写草稿；待发送附件在会话切换及重启后保留，仍支持移除。沿用最多 8 个附件、单个 8 MiB、合计 16 MiB 的限制，不支持文件夹。
- 修复 `/clear` 后新会话尚未生成原始记录，却被误判为无法恢复的问题；本地 `/context` 报告不会提前要求恢复不存在的记录。
- 原始 Claude 记录确实缺失时，可经确认「重建空白上下文」。本地聊天、草稿、附件及工作目录保留，队列暂停；此前聊天不会自动发送到新的 Claude 上下文。

## 验证与使用边界

发布流程要求 Windows、macOS 和 Linux 的检查、桌面测试、打包及实际包启动验证全部成功后上传资源。具体结果以本 Release 附带的源提交和 Actions 记录为准，开发验证见[验证记录](https://github.com/lixia3987-netizen/cc-desk/blob/v0.5.1/docs/VALIDATION.md)。日常推送和 PR 不触发构建，发布通过手动工作流执行。

开发阶段部分桌面验证受本地 Xvfb/X11 缺失影响，4 项进程验证也受容器 `ps` 故障影响，均已记录，不能视为通过；本次发布以三平台工作流的实际结果为准。自动测试使用本地协议与 PTY 测试进程，不代表真实 Claude 账号、全部代理与 CLI 版本、私有 Git 远程认证均已验收。

- 包未签名 / 公证，macOS 仅提供 Apple silicon arm64。Windows 单文件便携启动器、Linux FUSE 挂载和真实系统安全提示仍需实机验收。
- cc-desk 桌面应用仍需手动升级；内置更新功能仅更新本机 Claude Code CLI。Claude `settings.json.env` 中的代理尚未转发给应用的更新检查。
- 使用前需安装并登录本机 Claude Code CLI；cc-desk 不是 Anthropic 官方产品，不附带模型服务或账户。
