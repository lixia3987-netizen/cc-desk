# Claude Workbench / cc-desk v0.2.3

新增五套风格明显不同的主题，完整适配对话、终端、代码、Git 差异、审批、设置和弹窗。

| 主题 | 明暗 | 配色风格 |
| --- | --- | --- |
| 森野绿 | 深色 | 墨绿底色、薄荷高光；默认主题 |
| 云白靛 | 浅色 | 冷白、雾蓝、靛蓝 |
| 暖砂陶 | 浅色 | 奶油纸面、暖砂、陶土红 |
| 极夜蓝 | 深色 | 藏蓝、冰青 |
| 墨黑琥珀 | 深色 | 炭黑、烟棕、琥珀金 |

在「设置与连接 → 外观主题」点击预览，保存后记住；关闭弹窗取消未保存的选择。预览图见 [主题说明](https://github.com/lixia3987-netizen/cc-desk/blob/v0.2.3/docs/THEMES.md)。

正文、次要文字、代码与状态配色检查至少 4.5:1；焦点、关键控件边界和滚动条检查至少 3:1。浅色与深色分别设置终端调色板，切换时保留正在运行的进程、终端输出、对话和草稿，布局与按钮位置不变。

本版沿用 v0.2.2 的回复去重、恢复和可靠性修复。发布前运行三平台回归、桌面交互、打包及实际包启动检查；新增五主题切换、取消预览、保存/重启和同一 Shell 持续运行验证。没有调用收费模型。

同时修复九项连续操作问题：工作流目标/阶段指令和按文件审阅草稿跨切换及重启保存；终端模板追加而不覆盖；新建会话使用正确项目；长对话在会话切换和窗口缩放后保留阅读位置；终端模式不再误报附件错误；“保存并检测”检查当前 CLI 路径；“开始输入”明确首条任务启动方式；Git 在回合结束及重新聚焦后刷新并保留审阅内容。阅读位置目前仅在同一次应用运行中恢复。

新增会话内查找（Ctrl / ⌘ + F）、搜索结果定位与工具展开、旧消息分页，以及跨会话历史阅读恢复。顶栏“待处理”汇总各项目有效的审批和提问，点击直达请求；已过期的请求不会继续留作待办。搜索范围为工作台保留的本地记录，部分导入和长内容保留省略提示。

Windows x64 提供安装 EXE、单文件便携 EXE 和 ZIP；macOS arm64 提供 DMG/ZIP；Linux x64 提供 AppImage/tar.gz，附 `SHA256SUMS.txt`。完全退出旧版（包括托盘）后更新，数据目录不变。

包未签名/公证。实际包自动验证范围为 Windows NSIS 安装版/ZIP、macOS DMG 复制版/ZIP、Linux tar/提取的 AppImage；Windows 单文件便携启动器与 Linux FUSE 挂载仍沿用既有验证边界。
