# 字体与显示设置

本文适用于 cc-desk v0.4.0 及后续版本；系统字体选择、字体导入和分类设置未包含在 v0.3.0 安装包中。

在「设置与连接 → 外观与字体」中分别设置聊天内容、菜单与界面的字体和字号。聊天正文和输入框按聊天字号显示，消息标题与工具栏按菜单字号显示；代码和工具参数保留等宽排版，字号随聊天内容调整。终端使用独立的「连接与终端 → 终端字号」。

## 系统字体

打开设置后会读取本机已安装字体，按字体家族去重后列入「系统已安装」分组。通过「搜索系统字体」筛选名称，点击「刷新系统字体」重新读取。聊天和菜单可分别选择，即时预览；保存后重启继续使用。

「系统默认」沿用操作系统默认字体，也可明确选择其中一款已安装字体。应用只保存选择的名称，直接使用系统字体，不复制文件、不重新安装，也不上传字体列表。字体被卸载或当前系统缺少该字体时，显示回退到系统默认；所选名称保留，设置中标记未检测到。列表读取失败时可重试，已有选择、系统默认和导入功能仍可使用。

代码使用系统等宽字体，导入字体缺少的字符由系统字体补齐。v0.4.0 已移除全部 `@fontsource-variable/*` 依赖及预置字体资源，运行时不访问字体 CDN。需要指定字体时，可选择本机已安装字体或自行导入；不再保留旧 Fontsource 内置选项。

## 导入与恢复

点击「导入字体」后通过系统文件选择器选取 TTF、OTF、WOFF 或 WOFF2。单个字体上限为 20 MiB，最多保留 24 个导入字体；相同内容自动去重。仅导入你有权使用的字体文件，导入不会将字体安装到操作系统。

应用将字体复制到数据目录的 `fonts/`，按内容散列管理副本。数据目录位于「通知与后台」中。原文件移动或删除后，保存的字体仍可使用。移除条目只删除应用副本；若聊天或菜单正在使用该字体，该区域恢复系统默认。缺失或损坏的副本会显示错误并回退到可用字体，可重新导入或选择系统默认。

字体库的导入和移除立即保存。字体选择、字号和主题在设置窗口中即时预览；「保存设置」将其保留，取消、Esc、关闭按钮或点击弹窗外部会恢复已保存外观。不需要重新启动应用或正在运行的会话。

## 实现边界

- 系统字体通过 Electron 的 Local Font Access API 读取名称，不读取字体字节；仅向工作台主窗口的可信主页面授予 `local-fonts` 权限，其他页面、子框架和其他权限仍拒绝。
- 系统字体标识使用编码后的名称，CSS 字体名称独立转义；异常名称和无效标识不能写入设置。读取失败不会修改已保存的字体选择。
- 字体来源由主进程原生选择器决定，渲染进程仅能按字体 ID 读取应用副本。
- 导入检查扩展名、文件头、表范围、文件大小与压缩后上限；显示引擎进一步校验字体内容，读取失败会撤销新导入。
- 副本读取校验散列；索引损坏会保留原文件并报错。字体加载不会放宽页面 CSP 或开启任意本地文件读取。
- 默认聊天字号为 12 px，菜单基准字号为 13 px，终端字号独立设置。
