### 独立复核与修复

- 修复相同 revision 的外部配置改动复用旧 catalog：作用域绑定完整来源配置。
- 修复较早慢扫描覆盖较新目录：每会话独立发现代次，并以真实 I/O 门闩验证。
- 修复删除配置后 refresh 丢失 revision/退休 ID：已观察持久配置后缺失按只读错误处理，原有效快照保留。
- 统一来源设置和 registry 的控制字符校验，避免一个禁用的非法根阻断所有目录。
- 修复不完整 8 KiB 前缀把字节边界上的 `---` 误当 EOF 关闭符；只有完整文件才接受 EOF 结束分隔符。

## M2 第一批：内部运行链路与消息引用

本批完成 SK-05/06 的内部接入及其必要的动态副作用守卫。普通执行器创建链路不注入 `NativeSkillRuntime`，v1/旧 Skills 行为保持；缺少运行服务时显式拒绝新版引用。旧 `projectSkills` 仍由原 ProjectInstructions 加载与核验，尚未映射为新版 pinned/legacy 激活。M2 的输入框选择、设置界面、资源工具和完整 M3 连续性仍待推进。

| 项目 | 实现与边界 |
| --- | --- |
| 正文快照 | 私有目录内容寻址存储完整文件，校验全文/正文 hash、字节与格式；临时文件同步后以不可覆盖方式发布。默认 128 MiB、最多 8192 对象，同进程同目录串行限额；尚无跨进程并发写入与 GC |
| 查询与加载 | `list_skills` 查询冻结目录、分页限量；`load_skill` 核查来源、完整正文、输入与输出预算，并先保存不可变快照。超过预算明确失败，不截断后宣称成功 |
| 生效依据 | 真正 `tool_completed` 追加回执后才激活，记录下一请求的提供状态；该请求的完整模型响应已持久化后才确认。取消、传输错误和日志故障不会解除屏障 |
| 副作用守卫 | 同批含新加载时，任意工具排列中的写入/命令均拒绝；确认后重新准备。宿主策略版本保持稳定，技能版本/激活修订另写入预条件，准备、审批核验和执行前检查来源与运行归属 |
| 消息引用 | `ChatSendOptions`、IPC、preload、SessionService、队列及存储传递精确版本；严格输入校验，Claude/Shell 拒绝不适用字段。已有回执优先返回，避免重试重读新文件或重新执行 |
| 提交绑定 | 消息摘要包含规范化引用；启动审批同时绑定原参数、执行策略和技能引用。未带技能的历史文本/图片摘要逐字节兼容，已接受引用不能静默替换版本 |
| 宿主接入 | 内部 Native 执行器使用真实运行账本回执观察加载状态；连接凭据在目录/正文/输出及快照写入前检查。显式正文进入持久首轮指令；本地 MCP 在进程隔离准备后、实际服务启动前重核初始版本及审批，模型请求前再检查来源 |
| 暂时限制 | 内部新版运行关闭自动压缩与委派；技能历史阻止手动压缩及第二个新回合，原提交仍可返回回执。待 M3 完整传递正文和版本后解除，避免丢失约束 |
